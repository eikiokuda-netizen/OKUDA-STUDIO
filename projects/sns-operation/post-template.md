# Post Template

作品画像や制作内容を受け取ったら、このテンプレートをコピーして投稿案を作成します。

## 1. Input Brief

- 投稿ID:
- 希望ステータス: `idea`
- 対象チャンネル: Instagram / X / Both
- 希望投稿日:
- 作品名・企画名:
- 画像・動画の内容:
- 制作内容・背景:
- 伝えたいこと:
- 投稿目的: 認知 / 制作過程共有 / 完成報告 / 告知 / 販売導線 / その他
- 想定読者:
- 注意点・避けたい表現:
- 関連リンク:

## 2. AIへの依頼文

```text
以下のInput Briefをもとに、OKUDA STUDIOのInstagramとX向け投稿案を作ってください。
brand-guidelines.mdのトーンを守り、content-calendar.mdに追加できる行も作成してください。

[ここにInput Briefを貼る]
```
