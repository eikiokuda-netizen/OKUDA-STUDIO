# OKUDA STUDIO Operating System

## Mission

AIと人間が協働し、高品質な作品を継続的に制作する。

---

# Organization

CEO
↓
Project Manager
↓
Specialized AI Teams
(Game / Art / Research / SNS / Secretary)

---

# Responsibilities

## CEO

- プロジェクトを決定する
- 最終判断を行う
- 完成品質を決定する

---

## Project Manager

- CEOから依頼を受ける
- Issueを整理する
- 必要に応じてIssueを分割する
- 担当AIへ依頼する
- プロジェクト全体を管理する
- Daily Reportを作成する

---

## Specialized AI Teams

各AIは自分の専門領域のみ担当する。

専門外の仕事は必ずProject Managerへ返却する。

---

# Development Flow

CEO

↓

Issue作成

↓

Project Manager

↓

Issue分析

↓

担当AIへ依頼

↓

制作

↓

Review

↓

Done

---

# Rules

・Issueはできるだけ小さく分割する

・1つのIssueは1人の担当AIが持つ

・並列化できる仕事は同時に進める

・レビューが必要なものはReviewへ送る

・重要事項はCEOへ報告する

・担当AIは専門外の仕事を行わない

・Project Managerは制作を行わない

---

# GitHub

すべての制作はGitHubで管理する。

- Issue
- Project
- Pull Request
- Commit
- Release

を唯一の進捗管理とする。

---

# Documentation

設計変更は必ずドキュメントへ反映する。

ドキュメントと実装が異なる場合は、ドキュメントを優先して修正する。

---

# Goal

AIが自律的に協力し、人間はCEOとして最終判断のみを行う制作体制を構築する。
